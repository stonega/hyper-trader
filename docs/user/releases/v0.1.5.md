# Hyper Trader v0.1.5

- The default backend now uses `https://hyper-trader-backend.clawearn.xyz`,
  served by the VPS through Cloudflare.
- Change the backend URL in **Settings → Backend API**. The app saves your
  selection on the device, asks you to review the server receiving Portfolio
  account addresses, and offers **Use default** to reset it.
- Changing servers reloads market data, isolates cached data by server, clears
  open order drafts, and locks the trading session. An active order prevents a
  server change.
- Backend URL editing adjusts for the keyboard on iOS and Android.
- Order-book rows use the updated flat presentation.

Android downloads are provided separately for `arm64-v8a`, `armeabi-v7a`,
`x86_64`, and `x86`. Most current Android phones use `arm64-v8a`.
