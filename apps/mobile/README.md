# Hyper Trader mobile

The Expo application for Hyper Trader. Run installs and shared quality commands
from the repository root:

```sh
bun install
bun run mobile
```

The app entry is `src/app`, HeroUI/Uniwind styles are in `src/global.css`, and
Metro configuration is in `metro.config.js`. Run EAS and native Expo commands
from this directory.
